# 🧩 SteamLvlUp Full-Auto Farmer Pro

Пользовательский скрипт (Userscript для Tampermonkey) для автоматизации мини-игры **Puzzle Box**, сбора **Ежедневных, Еженедельных и Постоянных заданий**, а также вступления в **Розыгрыши** на сайте [steamlvlup.com](https://steamlvlup.com/giveaways).

---

## ✨ Основные возможности

### 1. 🧩 Автофарм игры Puzzle Box
- **Безопасный обход серверного античита**:
  - Автоматический выбор сложности (Сложная — `1400 XP`, Средняя — `800 XP`, Лёгкая — `400 XP`).
  - Настраиваемые паузы на генерацию стола и перед выходом из игры.
  - Честная активация серверного таймера сессии через эмуляцию перетаскивания кусочка пазла в 3D-координатах WebGL (`startTime` + `backGameProc`).
  - Выдержка случайного времени в заданном диапазоне (например, `240–260` сек для Сложной сложности) и распределение 63 шагов в `historyOfGame` перед вызовом `checkGameEnd()`.
- **Многораундовый цикл без перезагрузки страницы**:
  - Укажите количество игр в очереди (`Сколько игр собрать`) и нажмите `▶ Старт`.

### 2. 🎁 Задания и Розыгрыши
- **Ежедневные Задания (`daily`)**:
  - Автоматический сбор задания *«Посетите страницу Розыгрышей»* (`+500` монет в 1 клик).
  - Автоматическое открытие задания *«Пройдите проверку капчи»* (`+300` монет).
- **Еженедельные Задания (`weekly`)**:
  - Автоматический сбор всех готовых наград (`Получить`).
  - **Автозамена выполненных задач**: после получения награды, если доступны замены (`Доступно замен заданий > 0`), скрипт автоматически заменяет выполненное задание на новое.
  - **Автовыполнение задачи «Добавьте в избранное 30 наборов»**: скрипт сам загружает список наборов из Магазина (`/store/load`), отмечает 30 наборов в избранное (`/store/fav`), забирает награду, заменяет задание и очищает добавленные наборы обратно из избранного.
- **Постоянные Задачи (`global`)**:
  - Автоматический сбор монет по всем выполненным этапам (`Получить`).
- **Ежедневный и Еженедельный Розыгрыши (`giveaway`)**:
  - Автоматический переход на вкладку розыгрышей и поочерёдное вступление за `1` билет.

### 3. 🔍 Помощник и ИИ-решатель капчи
- **Живой переводчик**: переводит английское слово из задания капчи со смайликами Steam на русский язык прямо в модальном окне (встроенный словарь + автоперевод Google Translate API при неизвестном слове, например `Butterfly ➔ 🇷🇺 БАБОЧКА`, `Skull ➔ 🇷🇺 ЧЕРЕП`).
- **Нумерация ячеек `1..9`** и автоматический сдвиг виджета в сторону, если он перекрывает окно капчи.
- **Опциональное авто-решение через Gemini API**: если указать API-ключ Gemini, скрипт сам распознаёт нужные смайлики на картинке 3×3 и нажимает «Отправить».

## 🚀 Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для вашего браузера.
2. Откройте файл [`steamlvlup-autofarmer.user.js`](./steamlvlup-autofarmer.user.js) (или нажмите **Raw** на GitHub) и установите скрипт в Tampermonkey.
3. Перейдите на страницу [`https://steamlvlup.com/giveaways`](https://steamlvlup.com/giveaways).

## 📋 Changelog (История версий)

### `v1.3.0` (2026-11-11)
- **Feat**: Режим **«🎟 На все билеты»** (`useAllTickets`) — игры запускаются автоматически подряд, пока баланс билетов не достигнет `0`.
- **Feat**: Гибкое управление модулем **«Задачи и Розыгрыши»** — отдельные галочки **«📋 Задачи»** и **«🎟 Розыгрыши»** позволяют выполнять только сбор заданий, только вступление в розыгрыши, оба действия вместе либо полностью отключить модуль.
- **UI**: Обновлён дизайн виджета в стиле Dark Glassmorphism: верхняя строка живой статистики (`🎟 Билеты`, `🪙 Монеты`, `🏆 Игр`), карточная верстка и сворачиваемые блоки `<details>` для редких настроек пауз и ключа Gemini API.

### `v1.2.0` (2026-11-06)
- **Feat**: Автоматическое выполнение еженедельного задания *«Добавьте в избранное 30 наборов»* (добавление 30 наборов через API магазина ➔ получение награды ➔ замена задачи ➔ автоматическая очистка избранного).
- **Feat**: Автоматический сбор наград во вкладках *«Еженедельные Задания»* (с автозаменой выполненных задач при наличии доступных замен) и *«Постоянные Задачи»*.

### `v1.1.0` (2026-11-05)
- **Feat**: Модуль *«🎁 Ежедневные задачи и Розыгрыши»* (автосбор квестов на вкладке `Ежедневные Задания` и вступление в `Ежедневный` / `Еженедельный` розыгрыши).
- **Feat**: Помощник капчи со смайликами Steam (автоперевод искомого предмета на русский язык, нумерация ячеек `1..9`, автосдвиг панели управления и опциональное ИИ-решение через Gemini API).

### `v1.0.0` (2026-11-05)
- **Release**: Полностью рабочий MVP автофармера **Puzzle Box** (захват инстанса `p5`, определение активного экрана игры, честный запуск серверного таймера через 3D-координаты кусочка, генерация 63 шагов истории и цикл на заданное число игр подряд).
